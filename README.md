## 📱 الأقسام الرئيسية

**الحقول المتاحة:**
- 📕 اسم الكتاب
- 🏢 دار النشر
- 💰 سعر البيع للعميل
- 💵 سعر التكلفة (سعري)
- 📦 الكمية المتاحة

**الميزات:**
- ✅ إضافة/تعديل/حذف الكتب
- 🔍 بحث متقدم بالاسم أو دار النشر
- 📊 عرض الكتب في جدول منظم
- 💾 استيراد من ملفات Excel (xlsx)
- 📤 تصدير إلى ملفات Excel (xlsx)
- 💿 حفظ تلقائي في localStorage

### 2. 🛒 قسم الطلبات
نظام متكامل لإدارة طلبات العملاء مع تتبع الدفعات.

**حقول الطلب:**
- 👤 اسم العميل
- 📞 رقم الهاتف
- 🏠 العنوان
- 📋 تفاصيل الطلب (الكتب وكمياتها)
- 📝 ملاحظات إضافية
- 💳 المبلغ المدفوع
- 🔄 المبلغ المتبقي
- 🚚 تكلفة الشحن
- ✈️ حالة الشحن (قيد الإرسال/تم التسليم)
- 📅 تاريخ الإنشاء
- 💰 إجمالي المبلغ

**الميزات:**
- ✅ إضافة/تعديل/حذف طلبات
- 🔍 بحث بالاسم أو رقم الهاتف
- 💾 تحديث حالات الشحن
- 📊 جدول منظم بجميع الطلبات
- 📤 تصدير إلى Excel

- 💿 حفظ تلقائي في localStorage

## 🎯 دليل الاستخدام السريع

### إضافة كتاب جديد
1. اضغط على تبويب "📖 الكتب"
2. ملأ الحقول (الاسم، الناشر، الأسعار، الكمية)
3. اضغط "إضافة كتاب"
4. سيظهر الكتاب في الجدول

### إنشاء طلب جديد
1. اضغط على تبويب "🛒 الطلبات"
2. ملأ بيانات العميل (الاسم، الهاتف، العنوان)
3. اختر الكتب والكميات من القائمة المنسدلة
4. أضف تكلفة الشحن والملاحظات
5. اضغط "إضافة طلب"

### إدارة العروض
1. اضغط على تبويب "🎁 العروض"
2. أضف وصف العرض والمدة والسعر
3. ابحث واختر الكتب المشمولة في العرض
4. راجع ربح العرض وخصم العميل المحدثين تلقائياً
5. اضغط "إضافة عرض"
6. استخدم زر "تصدير إلى Excel" لحفظ عروضك خارج التطبيق

### تحويل طلب إلى فاتورة
1. من قسم الطلبات، اضغط على الطلب
2. اضغط "فاتورة"
3. ستظهر الفاتورة في قسم الفواتير

### طباعة فاتورة
1. اذهب إلى قسم "📋 الفواتير"
2. اختر الفاتورة المطلوبة
3. اضغط "طباعة"
4. استخدم نافذة الطباعة النظام

### تصدير إلى Excel
1. في قسم الكتب أو الطلبات
2. اضغط على "📤 تصدير Excel"
3. اختر موقع الحفظ
4. سيتم إنشاء ملف Excel تلقائياً

### استيراد من Excel
1. في قسم الكتب
2. اضغط "📥 استيراد من Excel"
3. اختر ملف Excel
4. سيتم استيراد الكتب تلقائياً

## 🔧 استكشاف الأخطاء

### ❌ التطبيق لا يبدأ
**الحل:**
```bash
npm install
npm start
```

### ❌ الرسوم البيانية لا تظهر
**الحل:**
- تأكد من وجود بيانات في التطبيق
- حاول تحديث الصفحة (Ctrl+R)
- تحقق من وحدة تحكم المتصفح (F12) للأخطاء

### ❌ Excel لا يصدر/يستورد
**الحل:**
- تأكد من تثبيت npm install بشكل كامل
- تحقق من صلاحيات الملفات
- جرب مع ملف Excel بسيط أولاً

### ❌ البيانات تختفي عند إغلاق التطبيق
**الحل:**
- تحقق من أن localStorage مفعل في المتصفح
- لا تمسح بيانات التطبيق من الإعدادات
- استخدم "تصدير Excel" لعمل نسخة احتياطية

### ❌ الواجهة لا تظهر بشكل صحيح
**الحل:**
- تحقق من حجم النافذة
- حاول تجديد الصفحة (Ctrl+R)
- استخدم F12 لفتح أدوات المطور وتفعيل responsive design

## 📖 المزيد من المعلومات

### 📝 ملاحظات التطوير

**أنماط الكود:**
- استخدام const/let بدلاً من var
- أسماء متغيرات واضحة وعربية
- تعليقات شاملة للدوال المعقدة
- معالجة الأخطاء مع try-catch

**معايير الجودة:**
- عدم استخدام Remote module (أمان)
- Context isolation مفعل
- عدم الخلط بين العمليات
- حفظ آمن للبيانات

**الأداء:**
- Chart.js مع destory() قبل إنشاء جديد
- تحديث ذكي للرسوم البيانية
- localStorage للبيانات السريعة
- معالجة فعالة لآلاف الطلبات

### � كيفية حساب الربح والمصروفات
- **إجمالي المصروفات**: يتم جمع كامل قيم المصروفات من قائمة `expenses` في الكود.
  - في `app.js` يتم حسابها باستخدام: `expenses.reduce((sum, expense) => sum + expense.amount, 0)`
- **إجمالي الإيرادات المدفوعة**: يتم جمع المبلغ المدفوع من كل طلب في قائمة `orders`.
  - الكود المستخدم: `orders.reduce((sum, order) => sum + order.paidAmount, 0)`
- **صافي الربح**: الفرق بين إجمالي المبالغ المدفوعة وإجمالي المصروفات.
  - الكود المستخدم: `const profit = parseFloat((totalCollected - totalExpenses).toFixed(2));`
- **نسبة الربح**: تُحسب من نسبة صافي الربح إلى إجمالي الإيرادات المدفوعة.
  - الكود المستخدم: `const profitPercent = totalCollected > 0 ? parseFloat(((profit / totalCollected) * 100).toFixed(1)) : 0;`

### 📚 كيف يُحسب الربح من الكتب والعروض
- عند إنشاء عرض، يتم جمع تكلفة الكتب المدرجة في العرض بناءً على سعر التكلفة الخاص بكل كتاب `myPrice`.
- ثم يُطرح هذا المجموع من سعر العرض النهائي `price`.
- الربح من العرض يُحسب هكذا:
  - `profit = price - cost`
- هذا يعني أن الربح من الكتب هو الفرق بين سعر البيع النهائي وقيمة التكلفة الفعلية للكتب المدرجة في العرض.

### 🔎 ملاحظات إضافية
- إذا كانت المصروفات أكبر من الإيرادات المدفوعة، يصبح صافي الربح سلبيًا ويظهر خسارة.
- الربح من الطلبات يعتمد على قيمة `paidAmount` لكل طلب، لذلك يجب التأكد من إدخال المدفوعات بشكل صحيح.

### �🔒 ملاحظات الأمان

1. **IPC Communication:**
   - استخدام ipcRenderer.invoke للاتصال الآمن
   - تحديد الخدمات المسموح بها في preload.js

2. **File Operations:**
   - استخدام dialog.showSaveDialog لحفظ آمن
   - استخدام dialog.showOpenDialog لفتح آمن
   - التحقق من امتدادات الملفات

3. **Data Storage:**
   - localStorage للبيانات المحلية فقط
   - بدون إرسال بيانات خارج النظام
   - تشفير اختياري للبيانات الحساسة
